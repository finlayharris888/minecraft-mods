Mob Probing Inventory Sorter

Minecraft Mob Probing

Gameplay · Server & singleplayer

Every hostile mob within 200 blocks of you starts hunting you. No more quiet nights: zombies, skeletons, spiders and the rest all head straight for your position.

  • Checks once per second and steers mobs towards the nearest player
  • Mobs within 40 blocks also lock on and attack
  • Players in Creative or Spectator mode are ignored
  • Pathfinds in short hops, so it works over long distances

Mobs only move in loaded chunks. Raise Simulation Distance to 13 or more in Video Settings to reach the full 200 blocks. On a multiplayer server, install it on the server.

Inventory Sorter

Quality of life · Client-side

One click sorts your inventory, chests, barrels, ender chests and shulker boxes. It runs entirely on your own client with ordinary slot clicks, so it works on any server without the server installing anything.

  • A Sort button on every chest, barrel and your inventory screen
  • Merges partial stacks, then sorts alphabetically with the biggest stacks first
  • Keyboard shortcut: R sorts the container, Shift + R sorts your inventory (rebindable in Controls)
  • Clicks are spread over a few ticks so servers do not flag you for spam
  • Never touches your hotbar, armor or offhand

Download v1.0.0

How to install

  1. Install Fabric Loader 0.20.1 or newer for Minecraft 26.3 (most launchers can do this for you).
  2. Download Fabric API for 26.3 and put it in your mods folder.
  3. Download the mod jars above and put them in the same mods folder.
  4. Start the game using your Fabric profile.

Requires Minecraft Java Edition 26.3 and Fabric API. These are early releases: if you hit a bug, please open an issue.
