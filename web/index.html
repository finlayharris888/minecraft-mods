How to install

  1. Install Fabric Loader 0.20.1 or newer for Minecraft 26.3. Most launchers can do this for you.
  2. Download Fabric API for 26.3 and put it in your mods folder.
  3. Download the mods you want from this page and put them in the same folder.
  4. Launch the game with your Fabric profile.

Found a bug or want a mod made? Open an issue on GitHub.
